# POETower — Cocos Creator 3.8.6

这是 `D:\\TowerPoe\\poe-tower` 的 Cocos Creator 移植版。按要求不迁移任何 Godot Sandbox/自动化沙盒场景；正式游戏、数据与设计/验收资料均保留。

## 运行

1. 使用 Cocos Creator 3.8.6 打开本目录。
2. 打开 `assets/scenes/main.scene`。
3. 点击“预览”运行。

也可以构建 Web Mobile；项目设计分辨率为 1080×1920，支持自适应缩放。

# 网格、导航、动态地形与地图规格

状态：DEMO 权威地图与寻路契约。

## 1. 坐标与网格

- 坐标原点为左上角，`x` 向右、`y` 向下，整数格坐标。
- 建造网格：6×4，位于城墙下方；塔放置、相邻与光环来源使用该坐标系。
- 战区网格：6×8，位于城墙外；敌人导航、入口、目标、图腾、冰墙和地面效果使用该坐标系。
- 两个网格逻辑独立；塔射程由表现映射把建造格中心转换到统一世界坐标。
- DEMO 所有塔占地 1×1；数据支持矩形 1×2、2×1、2×2，旋转后的占地必须由定义显式允许。
- 建造相邻只计算四向；光环和射程使用格中心间欧氏距离。

## 2. 地图数据层

地图由不可变定义和局内可变状态组成。

### 定义层

- 尺寸、入口、目标；
- 每格基础地形 ID；
- 建造层可建性和地形标签；
- 战区层移动代价、视线遮挡、地图效果；
- 地图全局规则与表现 ID。

### 局内状态层

- 塔占地；
- 图腾占位；
- 临时构造；
- 地面效果集合；
- `NavigationVersion`；
- 每种移动配置的导航场缓存。

定义对象不得被运行时回写。

## 3. 基础地形

| 地形 | 移动代价 | 建造 | 视线 | DEMO 规则 |
|---|---:|---|---|---|
| 道路 | 1.0 | 依地图层 | 不阻挡 | 敌人优先快速路线 |
| 普通地面 | 1.1 | 可 | 不阻挡 | 无额外效果 |
| 泥地 | 1.35 | 否/依地图 | 不阻挡 | 自然形成慢路线 |
| 浅水 | 1.5 | 否 | 不阻挡 | 感电地面扩散、冰缓持续 +50% |
| 软土 | 不用于战区 | 可 | 不阻挡 | 建造费 +10%，召唤补充间隔 -10% |
| 不可通行 | ∞ | 否 | 可配置 | 墙、深水、巨石等 |

沼泽地图路径上的敌人处于 `terrain.wet` 时：感电积累效率 +20%、冻结积累效率 +15%、灼烧伤害 -15%。

## 4. 导航场

DEMO 使用“从目标反向计算的加权流场”，不让每个敌人独立执行 A*。

### 构建

1. 以所有城墙目标格为距离 0；DEMO 只有 1 个目标。
2. 使用 Dijkstra 按移动代价向四邻格扩张。
3. 为每个可达格记录 `cost_to_goal` 与 `next_cell`。
4. 同价依次选择：更少转弯、固定方向优先 `Down, Left, Right, Up`、坐标字典序。
5. 任一入口不可达则导航定义非法。

### 版本

- 基础地图加载后版本为 1。
- 会改变可通行性的构造集合发生实际变化时，`NavigationVersion + 1` 并重建场。
- 同一逻辑步的多个构造变化合并为一次重建。
- 地面减益不改变 DEMO 导航代价，不触发版本变化。

### 多移动类型扩展

导航缓存键为 `MovementProfileId + NavigationVersion`。DEMO 只有 `movement.ground`；未来飞行、无视泥地或畏火敌人可使用不同配置，不改变敌人接口。

## 5. 敌人移动

- 敌人状态保存当前格、下一格、格间进度 `[0,1)` 和所用导航版本。
- 到达格边界时读取最新导航场的 `next_cell`。
- 当前下一格突然被堵时可立即请求替代方向；其他非必要改路遵守 0.75 秒保护。
- 改路不能瞬移、倒退到刚离开的格，除非除此之外无合法路径；若出现无合法路径属于系统错误并暂停该敌人、记录完整诊断。
- “最接近城墙”使用 `cost_to_goal + 当前格间剩余代价` 排序。

## 6. 冰墙构造

- 冰墙来源为 `tower_frost_barrier` 的构造技能；玩家从塔详情选择战区格。
- 每塔独立冷却 18 秒；每塔同时最多 1 段；全场最多 2 段；持续 6 秒。
- 放置不额外消耗金币、不使用充能；建造冰障塔和其升级是机会成本。
- 冰墙占 1 格，视为不可通行，不可受伤、不可被敌人攻击。

### 放置验证

1. 来源塔有效、技能可用且冷却完成；
2. 当前状态允许建造操作；
3. 格子位于战区；
4. 不是入口、目标、已有构造或敌人当前格；
5. 每塔和全局上限未满；
6. 模拟加入后所有入口仍可达目标；
7. 成功后创建构造、开始冷却并递增导航版本。

任何失败都不开始冷却。冰墙自然到期时移除并统一触发导航更新。

## 7. 图腾与嘲讽

- 图腾占战区逻辑格，但不阻挡导航、视线或地面效果。
- 同一战区格最多 1 个图腾；图腾不可被选择为伤害目标。
- 嘲讽图腾周期性创建 `TauntEffect`，使范围内敌人暂停推进并面向诱饵表现点。
- 嘲讽按持续时间结束：普通 2 秒、精英 1.25 秒、首领 0.5 秒；同来源 3 秒抗重施。
- 嘲讽不修改导航场；结束后敌人从当前格继续读取流场。

## 8. 地面效果聚合

每个战区格持有按 `GroundEffectKind` 索引的聚合槽：

- 同类多个来源只保留强度最高者；最高者相同则保留结束 tick 最晚者；
- 不同类型可共存；
- 每 0.25 秒（8 个逻辑 tick，最后一次允许误差 1 tick）批量作用于格内敌人；
- 当前软上限 48 个非空效果格，超出时移除剩余时间最短的非首领来源效果并记录警告。

| 效果 | 持续 | 规则 |
|---|---:|---|
| 燃烧地面 | 4秒 | 每秒造成基准塔 DPS 25% 火伤；每秒 +15 灼烧积累 |
| 冰缓地面 | 5秒 | 移速 -20%，视为寒意；默认不增加冻结积累 |
| 感电地面 | 4秒 | 承伤 +10%，受到的感电积累 +25% |

感电地面的承伤与正式感电状态取较高值，不相加；积累增幅正常生效。

### 浅水联动

- 感电地面生成在浅水格时，按 `Up, Left, Right, Down` 顺序向相连浅水扩散，最多额外 2 格。
- 扩散格共享来源、强度和结束 tick，不继续递归扩大上限。
- 冰缓地面在浅水上的持续时间乘 1.5。
- DEMO 不实现燃烧蒸发冰缓、冻结水面或地面驱动寻路；保留新的地面反应处理器接口。

## 9. 视线与射程

- DEMO 沼泽地图没有动态视线遮挡，但接口支持 `blocks_projectile`。
- 射程先按世界中心距离判断，再对需要视线的技能执行格线穿越测试。
- 边界正好穿过遮挡格角时视为被遮挡，避免平台差异。
- 投射物生成后若地形变为遮挡，当前投射物继续；下一次目标选择使用新视线。

## 10. 表现与调试要求

- 建造/构造预览显示格子、合法性、费用、射程和关联。
- 冰墙预览显示当前主路线和放置后的主路线；完全断路使用图标与文字。
- 调试层可切换显示坐标、移动代价、`cost_to_goal`、`next_cell`、导航版本和地面槽。
- 路径重建记录耗时、版本、改变格数和受影响移动配置。

## 11. 验收场景

- Given 两条可达路线，When 冰墙封住当前短路，Then 敌人在格边界切换到替代路线。
- Given 冰墙会封死最后路线，When 放置，Then 返回 `would_block_all_paths` 且无状态变化。
- Given 50 个敌人共享地面移动配置，When 冰墙变化，Then 只重建一次共享导航场。
- Given 感电地面落在连续浅水，When 创建，Then 主格加最多 2 个相邻水格获得同结束 tick 的效果。
- Given 冰墙到期和另一堵墙同 tick 创建，When 结算构造变化，Then 导航版本只增加一次。

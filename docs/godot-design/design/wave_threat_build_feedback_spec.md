# 波次威胁预告与建造操作反馈规格 v1

更新时间：2026-08-16  
状态：UX-003 已确认实现规格；DEMO 默认流程的一部分

## 1. 目标

玩家开波前能回答“来什么、从哪来、危险在哪”；建造前能回答“能否放、覆盖哪里、花多少钱”；操作后能立即理解成功、失败和金币变化。

## 2. 范围与规则

### 2.1 波次威胁分析（纯数据，可测）

- 数据源只有 `WaveDefinition` / `WaveSpawnGroupDefinition` / `EnemyDefinition`（只读真值），UI 不复制玩法数据。
- 出怪完成时间 = `max(StartSeconds + (Count - 1) * IntervalSeconds)`。
- 威胁规则（集中实现于 `WaveThreatAnalyzer`）：
  - 双路：不同 `PathIndex` 数量 ≥ 2；
  - 高数量：总数 ≥ 25；
  - 密集：任一生成组数量 ≥ 10 且间隔 ≤ 0.20 秒；
  - 高速：任一敌人移速 ≥ 110 px/s；
  - 高耐久：任一敌人生命 ≥ 100；
  - 抗电：任一敌人闪电抗性 > 0；
  - 持续攻城：`AttacksWallContinuously`；
  - 首领：持续攻城且生命 ≥ 1000。
- 提示为非强制一行文案，按压力优先级选键：首领 > 抗电 > 高速 > 密集 > 双路 > 高耐久 > 默认；不给唯一塔答案。

### 2.2 波次预告面板与入口高亮

- “波次预览”按钮打开专用可关闭面板（替代旧 Message 摘要），显示：波次序号与 DisplayName、总敌人数、入口数、约几秒出完、理论金币、每组“入口N｜敌名 ×数量 · 生命 · 速度 · 抗电(非零) · 起始/间隔”、威胁标签、一行提示。
- 打开面板时 `WaveEntranceOverlay`（非阻塞 Node2D）脉冲高亮本波涉及的入口并绘制“入口N”标签，与组行标识一致；关闭/开波/离场时清理。不向玩家展示裸 `PathIndex`。
- 开始按钮在 `WavePreview` 阶段显示“开始第 N 波”；开始波次时关闭面板与高亮。

### 2.3 建造预览

- `BuildPlacementPreview` 是只读结果对象（cell、塔、实际费用、购买后金币、范围、合法性、稳定拒绝码）；`EvaluateBuild` 与 `TryBuild` 共用同一合法性/费用计算，预览与执行不得漂移。
- 鼠标悬停格显示半透明塔落点、真实范围、格子状态（可建青色、占用黄色、非法/不足红色）与非颜色原因（HUD“花费 N → 剩余 M”或“无法建造：原因”）。
- 触摸无悬停：选塔后塔池按钮常显实际费用与范围、金币不足差额，并显示选中态；提示行显示“已选择 X · 费用 N · 范围 R”。
- 失败不扣金、不改占用、不退出建造模式。

### 2.4 操作结果反馈

- 建造成功：约 180ms 落成 Tween（0.86 → 1.08 → 1.0）+ 扩散圈 + 塔旁“-N 金币”浮字。
- 升级成功：“Lv.a→Lv.b”浮字 + 实际扣费 + 塔身强化闪光。
- 出售成功：淡出残影 + “+N 金币”浮字。
- 失败：目标格 0.3s 红色闪烁 + 相关按钮红色短闪 + 具体错误文案；金币/等级/槽位/占用/UI 状态与规则一致。
- 反馈金额全部来自结算后的信号参数，与真实扣款一致；反馈节点到期释放，无泄漏。

### 2.5 非目标

自动开波倒计时、实时剩余敌人分类、完整时间轴、敌人百科、唯一塔推荐、连续建造、音频、正式美术。

## 3. 验收

- Given 波 2 待开始，When 打开预告，Then 显示 37 名敌人、2 个入口、理论金币 110、约 4.84 秒出完及两组真实数据，入口覆盖层可对应。
- Given 波 3，When 查看预告，Then 显示高速标签但不硬指定某座塔。
- Given 已选静电针且金币足够，When 指向合法空格，Then 显示实际范围与“花费 80 → 剩余金币”，提交后只扣一次并播放局部反馈。
- Given 占用格或金币不足，When 尝试建造，Then 不扣金、不改占用、保持建造模式并显示具体原因。
- Given 升级/出售，When 成功，Then 局部动画和浮字与真实等级/金币完全一致。
- 540×960 下波次面板、开始按钮与建造操作不被裁切；1080×1920 正常。
- 确定性验收：`UxFeedbackSandbox` 覆盖威胁规则纯断言与建造预览/执行一致性；`--visual` 模式驱动正式 DemoGameplay 捕获双分辨率证据帧并输出面板字符串日志。

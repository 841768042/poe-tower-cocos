# POETower 战斗反馈与数值可读性计划 v1

更新时间：2026-08-16  
状态：建议的下一里程碑；待按优先级逐项实现与试玩验收

## 1. 一句话体验目标

玩家无需盯着顶部数字或猜测后台规则，也能从单个敌人的连续表现中看懂“被哪座塔命中 → 感电如何积累与触发 → 雷暴是否消费成功 → 敌人为何死亡 → 本次击杀得到多少金币”，并能在花钱前看到塔与辅助升级会改变的具体数值。

## 2. 现状判断

当前已经存在塔攻击 VFX、敌人 0.14 秒受击变色、0.5 秒死亡下坠/旋转、血条和感电文字，但反馈仍不成链：

- 受击只有短暂颜色变化，缺少位移、命中点和伤害结果层，密集战斗中容易看不见。
- 感电积累与完整感电共用小号文字区域，没有稳定的图形状态；感电被消费时也没有独立爆发提示。
- 击杀金币只改变顶部总额，玩家无法把某次死亡与收益建立因果关系。
- 塔详情只显示职责、射程和辅助槽；升级只说“约 +20%”，没有当前值、升级后值和实际差额。
- 辅助条目有描述文本，但缺少安装/升级后关键数值的前后对照，难以形成构筑判断。

## 3. 优先级

### P0：战斗因果链（必须先做）

1. **受击确认**
   - 保留颜色闪烁，并增加 0.08～0.12 秒的轻微压缩/回弹或沿来袭方向 2～4 px 位移。
   - 在命中点显示短寿命火花/冲击环；普通伤害数字默认可关闭或合批，避免群虫波刷屏。
   - 同一敌人 0.08 秒内多次命中时合并表现，但伤害结算保持逐次确定性。

2. **感电三阶段**
   - `0～99%`：敌人脚下或血条旁显示分段电量环/条，颜色随积累增强。
   - `IsShocked`：蓝白描边、周期电弧和明确图标；不要只依赖文字或颜色。
   - `ConsumeShock`：紫白爆裂、状态图标碎散并短暂显示“消费”提示，与普通雷暴命中区分。

3. **死亡与金币**
   - 死亡动画保留 0.35～0.5 秒，击杀结算后在死亡位置生成 `+N 金币`。
   - 金币文字上升 36～52 px、持续 0.55～0.75 秒并淡出；同一小区域 0.12 秒内的群体击杀可合并为 `+N`，避免 25 只群虫产生 25 行文字。
   - 突破城墙不得显示金币；Boss/精英奖励使用更高层级但不改变结算规则。

### P1：花钱前看懂结果（必须）

为每座塔提供统一的“有效属性快照”，UI 与实际攻击使用同一计算来源，至少显示：

- 当前伤害或核心效果值；
- 攻击间隔与换算 DPS（不适用的塔显示冷却/脉冲周期）；
- 有效射程；
- 目标数、连锁数或范围半径；
- 感电积累、光环增幅、冰墙持续/冷却、嘲讽范围/持续等职责专属值；
- 当前威力等级与已安装辅助造成的最终修正。

升级面板使用 `当前值 → 下一等级值（差额）`；辅助宝石安装与升级也展示受影响字段的前后值。若某个辅助尚未实现专属逻辑，必须明确标记，不得只显示看似有效的描述。

### P2：战场威胁与操作反馈（应该）

- 每波开始前在对应入口显示敌人类型、数量和路线方向；精英/Boss 提供独立预警。
- 敌人进入城墙前最后一格时提高威胁描边或显示突破警告，城墙受击同步闪动与数值跳变。
- 建塔成功提供落地动画、费用飞字和射程短显；升级提供塔身脉冲、等级上浮与关键属性变化。
- 出售显示回收金币飞字；非法操作除文字外提供按钮/目标格抖动和错误色。
- 2×速度下保持反馈可读：缩短持续时间但不完全跳过关键状态触发、消费、Boss 死亡和结算表现。

### P3：声音、震动与镜头（可以）

- 三种核心电塔应有不同瞬态轮廓：静电针短促、电弧连跳、雷暴低频重击。
- 状态触发、状态消费、击杀、金币、建造、升级、城墙受击分别使用短音效，限制同帧并发和响度。
- 雷暴消费、Boss 死亡和城墙重击允许 1～3 px 轻微镜头冲击；提供“降低闪烁/关闭镜头震动/关闭伤害数字”选项。

## 4. 第一实现切片

只做一条可完整观察的链路：静电针命中与积累 → 完整感电图形状态 → 雷暴消费爆裂 → 死亡 → `+N 金币` 上升动画，并同时让静电针、雷暴的详情显示实际伤害、间隔、射程、感电/范围以及升级前后值。

本切片暂不做正式音频、全六塔专属动画、所有辅助宝石预览、暴击/抗性浮字或复杂镜头系统。先证明反馈链能让玩家复述因果关系，再扩展到电弧、光环、冰障和图腾。

## 5. 验收

- Given 静电针对一个未感电敌人连续命中，When 积累从 0 到阈值，Then 玩家可从图形进度与触发表现判断何时进入完整感电。
- Given 雷暴命中完整感电敌人，When 状态被消费，Then 消费爆裂与普通雷暴命中明显不同，状态指示同步消失。
- Given 敌人被击杀，When 奖励结算，Then 死亡位置出现正确 `+N 金币`，顶部金币同步增加；突破敌人没有金币飞字。
- Given 同区域 10 个群虫在 0.12 秒内死亡，When 显示奖励，Then金币表现可合并且不会产生不可读的文字墙。
- Given 玩家选中塔并打开升级/辅助界面，When 尚未支付，Then 能看到当前值、预览值和差额；取消不会改变运行时数据。
- Given 游戏处于 2×，When 状态触发、消费和 Boss 死亡，Then 关键反馈仍至少显示一个可辨识周期。

## 6. 成功指标与停止条件

- 至少 4/5 名新玩家首局能指出哪个敌人“已感电”、哪次雷暴“消费了感电”、一次击杀奖励来自哪里。
- 至少 4/5 名玩家在升级前能正确回答伤害、间隔或职责专属值将如何变化。
- 若反馈导致群虫波遮挡路线或平均帧时间明显上升，首先合批伤害/金币文字和限制粒子并发，不删除状态触发与消费反馈。
- 若玩家仍看不懂联动，停止新增塔与辅助内容，继续调整反馈层级、颜色/形状冗余和时序。

## 7. 第一实现切片记录（2026-08-16）

状态：已实现，等待真实试玩验收。

### 已交付

- **击杀奖励事件**：`BattleRuntime` 新增强类型 `KillRewardGranted(entityId, rewardGold, worldPosition)` 信号，只在 `Defeated` 结算时发出（`Breached` 不发），携带奖励金额与死亡世界坐标。
- **受击确认**：保留 0.14 秒闪色，新增 0.1 秒压缩回弹（0.88/1.10 → 1.0）；同一敌人 0.08 秒内多次命中合并表现，伤害结算仍逐次确定。
- **感电三阶段**：敌人脚下分段积累环（buildup/threshold，颜色随进度增强）；完整感电显示蓝白双环、旋转电弧与闪电图标并随周期脉冲；`ConsumeShock` 触发紫白爆裂 + 短暂“感电消费”标签，状态图形随状态清除同步消失。实现位于 `ShockStatusIndicator`（表现层，由 `EnemyPresentationComponent` 订阅 `ShockTriggered`/`ShockConsumed` 领域事件驱动）。
- **死亡与金币**：保留 0.5 秒死亡动画；`CombatFeedbackLayer` 在死亡坐标显示“+N 金币”，44px 上升、0.65 秒淡出，100px/0.12 秒窗口内合批，不拦截输入、位于 HUD 层之下。
- **有效属性共享计算**：新增 immutable `TowerEffectiveStats` 与 `TowerStatsCalculator`（`scripts/gameplay/combat/`）。`TowerAttackComponent.GetEffectiveStats()` / `PreviewPowerUpgrade()` 与真实攻击复用同一公式（等级、辅助、天赋、光环全部计入）；预览零副作用。
- **塔详情与升级预览**：静电针/雷暴塔上 TIPS 显示实际伤害/间隔/DPS/射程/感电或范围；升级页显示 `Lv.X → Lv.X+1` 与逐项当前→下一等级差值；取消不改变任何运行时状态。其余塔保持既有通用描述，不显示伪造数值。
- **确定性验收**：`CombatFeedbackSandbox` 无头验证感电触发/消费事件、Defeated 奖励金额/坐标正确、Breached 无奖励事件、Power 预览零副作用且升级后与预览一致、正式场景包含反馈层；附带 `--visual` 实时截图模式用于视觉检查。

### 已知边界

- 详情与升级页的新文案为代码常量；待内容文案流程放开后迁移进配置表（本任务 `resources/config/**` 不可改）。
- 视觉效果尚未经真实玩家试玩复测。

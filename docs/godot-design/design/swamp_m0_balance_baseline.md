# 沼泽第一章 M0 数值基线

本报告只锁定扩展内容前的真实运行基线，不把计划占位值或线性代理当作测量。机器可读权威产物由 `tools/verify-swamp-m0-balance-report.ps1` 从战斗矩阵、独立战斗回放、200-seed 掉落分布和生成配置重新生成。

## 已测基线

- 三档无天赋 Profile 的装备伤害乘区分别为 1.00、1.12、1.16。
- 五类构筑为 balanced、shock、arc、storm、control_low；共 15 个固定种子案例，每个双跑且摘要哈希一致。
- 低档 balanced 在固定 60 Hz 下于第 3 波、tick 1793 失败：击杀 62、漏怪 20、结束金币 220、塔投入 300、城墙 0。
- 高档 balanced 到达第 4 波，击杀 73、漏怪 19；这表明当前装备层有可测提升，但现有九波 DEMO 并非可通关平衡目标。
- 八个运行时轴均完成 -10% / 0 / +10% 双跑；Boss 冷却和召唤能力在 M0 不存在，必须在首次 Boss 里程碑 M2 测量，禁止使用代理冒充。

## 成长预算

- 强化每级固定增加 20% 基础伤害，等级 1～5 的乘区为 1.0 / 1.2 / 1.4 / 1.6 / 1.8，累计金币为 0 / 80 / 220 / 440 / 760。
- 辅助技能按行为层记账，不折算成单一 DPS。当前配置的直接 `damage_more` 范围是 -20%～+50%；深度传导、额外连锁、集中雷暴分别锁定感电/射程、连锁/衰减、伤害/半径的真实权衡。
- 当前无天赋基准的天赋贡献为 0；40% 是下一章成长空间的设计护栏（允许区间 30%～50%），不是实测强度。
- 已配置层在不含天赋时的理论直接乘区上限为 `1.80 × 1.50 × 1.16 = 3.132`；它只用于防止跨系统重复吃预算，不代表开局经济可达或章节目标强度。

## 分布与风险

200 个固定种子、每种子 53 次事件的基线随机掉落均值为 1.07（理论 1.06），含教程保底总均值 1.405，Magic 比例约 49.11%，保底触发率 33.5%。数量乘区 +10% 后随机均值升至 2.14，存在离散取整悬崖。因此在重做整数数量规则并重新采样前，禁止把全局数量乘区调到 1.0 以上。

## 回滚

机器报告保存三塔、经济和掉落原值。任一固定案例哈希、战斗内容哈希、低档 balanced 精确结果、存档不变断言、生成配置无差异或 0 警告 0 错误构建失败时立即停止并恢复原值。统计回滚区间为：随机掉落均值 [0.80, 1.32]，Magic 比例 [0.38, 0.60]。

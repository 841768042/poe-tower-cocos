# 《流亡筑界师》（暂名）产品愿景

状态：长期方向，DEMO 细节以 `demo_scope.md` 为准。

## 一句话体验

玩家扮演一名以装备、天赋和建造技艺改写防御规则的建筑师，在竖屏战场下方自由布置多塔流派，抵御上方怪潮，并用战利品持续重构自己的防线。

## 产品支柱

1. **流派是一套塔阵**：输出、施加状态、消费状态、控制、光环和图腾共同构成循环；不以单塔包办全部功能。
2. **战利品改变建造决策**：装备词条影响塔类别、标签、地形、费用和技能规则，而不只是全局数值增长。
3. **地图也是构筑部件**：沼泽、森林、城市等生态影响可建格、路径、视线、状态和地面效果。
4. **战前规划与战中建造并重**：局前选择塔池和装备，局内只执行建造体系操作；建筑师主动技能留待后续。
5. **复杂度必须可读**：所有词条、联动、状态积累、路线变化和失败原因都必须在行动前可预览、行动后可解释。

## 长期系统

- 竖屏 2D 塔防；城墙外为怪物战区，城墙下为建造区。
- 塔类别：元素、投射物、召唤、光环、图腾。
- 流派以冰、火、电等标签内部联动为主，少量跨流派桥接。
- 每种塔提供 10 个候选辅助宝石，单座塔最多装配 5 个并可局内升级。
- 建筑师拥有装备、随机词条、传奇机制、等级、天赋与通货制作。
- 装备品质：普通、魔法、稀有、传奇；使用原创名称、美术、数值与机制表达。
- 地图与动态地形支持燃烧、冰缓、感电地面，以及冰墙等临时构造。
- 怪物掉落局内金币与临时战利品；金币局末清零，胜利提交战利品，失败全部丢失本局所得。

## 长期体验循环

整理装备与天赋 → 选择地图和出战塔池 → 局内建造与战斗 → 胜利带回装备/通货 → 制作和调整流派 → 挑战更复杂地图。

## 目标玩家

- 喜欢塔防布阵、克制、路线与经济管理的玩家。
- 喜欢 ARPG 掉落、词条、流派和规则型传奇装备的玩家。
- 接受中等复杂度，但要求系统反馈明确、失败能够归因。

- 不直接复制现有商业作品的专名、美术、音效、地图、剧情或完整物品机制。
- 不以完全免疫作为常规克制手段。
- 不让后台复杂度超过玩家可观察的信息。
- 不为尚未验证的终局内容提前建立专用框架；先通过 DEMO 证明核心一分钟和完整单局。
